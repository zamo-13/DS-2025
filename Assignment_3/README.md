# DSA Moderation Dashboard — Assignment 3

An interactive dashboard comparing how TikTok and X (Twitter) moderated
content in Germany during the first half of 2025 — how much of it was
automated, how specific their reporting is, and how moderation activity
shifted around the February 2025 election.

The data comes from the EU's DSA Transparency Database, pre-processed by
a separate bachelor's thesis project and exported here as plain CSV files.

---

## How to run it (step by step)

You only need to do this once per computer — after that, just repeat step 3
whenever you want to open the dashboard.

**1. Open a terminal**
On Windows: click Start, type `PowerShell`, press Enter.

**2. Go to this folder and activate the environment**
Copy-paste each line below, pressing Enter after each one:
```
cd "C:\Users\MoZa\OneDrive - Universität Paderborn\0_UPB\6\Data Viz\datavis-2026\Assignment_3"
.venv\Scripts\activate
```
Your prompt should now start with `(.venv)` — that means it worked.

*(First time only, if `.venv` doesn't exist yet: run `python -m venv .venv`
then `.venv\Scripts\activate` then `pip install -r requirements.txt` before
continuing.)*

**3. Start the app**
```
streamlit run app.py
```
A browser tab should open automatically. If it doesn't, copy the
`Local URL` printed in the terminal (usually `http://localhost:8501`) into
your browser.

**4. Stop the app**
Click back into the terminal window and press `Ctrl+C`.

## What you'll see

The dashboard has 4 tabs:

1. **Overview** — the headline contrast: TikTok resolves ~95.5% of German
   moderation decisions fully automatically, X resolves almost none that way.
2. **Platform Comparison** — what kind of content each platform moderates
   most, shown as side-by-side bar charts on a shared scale.
3. **Reporting Granularity** — how specific each platform is about the
   outcome of a decision. X reports "Other" (no specific outcome) for 100%
   of its decisions; TikTok specifies an outcome most of the time.
4. **Election Window** — how moderation intensity (normalised by each
   platform's user base) changed over time, viewable as Daily, Weekly, or
   Monthly (default: Weekly), with the 23 February 2025 German snap election
   marked, plus a January → February comparison table.

Use the **Platform** filter in the sidebar to show just TikTok, just X, or
both.

## Where the numbers come from (for anyone checking the data)

Everything the app displays is read from eight CSV files in `dashboard_data/`.
Those files are **not placeholders** — they were generated by running the
real export script against the full dataset.

**Data Source:** The dataset used in this app originates from DSA
Transparency Database, TikTok/X, Germany, H1 2025 data collection.
---

## Project structure

| File / folder | What it is |
| --- | --- |
| `app.py` | The dashboard itself (the 4 tabs described above) |
| `dashboard_data/` | The 8 real CSVs the app reads — regenerated from source data |
| `requirements.txt` | Python packages needed to run the app |
| `.venv/` | The isolated Python environment for this app (not committed to git) |

This app intentionally does not import any code from the thesis repository —
it only reads the exported CSVs, the same way the thesis pipeline treats its
own external data folder (`C:\BA_Data`).
